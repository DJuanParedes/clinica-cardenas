API REST v1 · Clínica Dental Cárdenas

347 rutas en 45 controladores · generado del código del servicio 2.12 · base https://clinica-cardenas.chilecentral.cloudapp.azure.com/api/v1

Cómo se usa

Autenticación: POST /api/v1/auth/login (personal) o POST /api/v1/portal/auth/login (paciente) devuelven un JWT. Las demás rutas llevan la cabecera Authorization: Bearer <token>. Sin token o con token vencido: 401; sin el privilegio del rol: 403.

Reserva idempotente: POST /api/v1/portal/book acepta Idempotency-Key: si la misma clave llega dos veces, no se crea una segunda cita.

Formato de error:

{"code": "VALIDACION", "message": "Revisa los datos.", "fields": {"email": "Correo no válido"}, "status": 400}

Todas las rutas responden también sin la versión (/api/...) por compatibilidad con la web.
